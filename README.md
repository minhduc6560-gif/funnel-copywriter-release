# Copywriting Funnel

Writes reusable copy for lead, webinar, and sales funnels.

## Included skills

- `ldg-lead-funnel-copywriting`
- `ldg-webinar-funnel-copywriting`
- `ldg-sale-page-copywriting`
- `document-source-ingestion`

## Install

```bash
hermes profile install github.com/minhduc6560-gif/funnel-copywriter-release --alias
```

The profile is installed automatically as `copywriting-funnel`; no `--name` option is needed.

The distribution excludes credentials, memories, sessions, logs, browser profiles, and project data. Bring your own model/provider configuration and integration credentials.
